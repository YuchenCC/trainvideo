# Scene Issue Files Index

这些文件由 `scene-issues.md` 拆分生成，每个文件对应一个可并行执行的 scene HTML 任务。

## 并行执行建议

- 每个执行线程领取一个 `issue-XX-scene-XXXX.md` 文件。
- 只实现该 issue 指定的 HTML 输出文件，不修改其他 scene。
- 输出目录统一为 `compositions/scenes/`。
- 每个任务完成后按文件内 `### 验收标准` 自检。
