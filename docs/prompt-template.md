# HyperFrames Prompt Template

每章 Prompt 必须包含以下结构。

```text
画面风格：
浅色科技背景，技术讲解博主风格，清爽、专业、有图解感，不做传统企业宣传片。

画面主体：
说明本镜头的主要内容，例如“飞书群聊消息被 AI 解析成结构化变更单”。

画面结构：
左侧是什么，右侧是什么，中间是什么流程。

视觉元素：
关键词标签、箭头、流程线、卡片、截图占位、高亮框。

颜色要求：
蓝紫为主色，橙色表示 AI，红色表示风险，绿色表示通过或完成。

字幕要求：
主字幕一句话，不超过 18 字；关键词不超过 4 个。

动效要求：
元素依次出现，重点区域放大，高亮框标注，避免炫技粒子。
```

## Example

```text
浅色科技背景，技术讲解博主风格。画面左侧是飞书群聊消息：“支付需求修改，不做微信支付，只做支付宝”；中间是橙色 AI Agent 节点，正在解析消息；右侧生成结构化变更卡片，包含涉及需求、变更内容、工作量影响、进度风险、依赖风险。使用蓝紫主色，橙色突出 AI，红色突出风险，绿色表示已建档。添加手绘箭头和流程线，主字幕为“群聊不是流程终点”，关键词为“自动解析、影响分析、系统建档、变更台账”。整体清爽专业，不要赛博朋克，不要复杂粒子。
```
