# evidence-card

Reusable evidence card for chat, spreadsheet, status, and risk blocks.

## Purpose

Use when a scene needs product-like proof without relying on screenshots.

## Default Structure

```html
<article class="evidence-card">
  <header><span>飞书消息</span><b>消息爆炸</b></header>
  <div class="evidence-lines">
    <i></i><i></i><i></i>
  </div>
</article>
```

## Rules

- Keep cards as simplified UI evidence, not dense real tables.
- Default size range: `360-460px` wide, `190-260px` tall.
- Use 2-4 visible rows or lines per card; text must be readable at video size.
- Pair every card with one clear label or status.
- Highlight only 1-2 card areas at the same time.
- Entrance: cards can enter from different directions, but should settle into a stable grid.
