# Quality Checklist

## Information

- 这一章是否只讲了一个核心观点？
- 评委不听口播，只看画面能否大概理解？
- 主字幕是否足够短，不超过 18 字？
- 关键词是否不超过 4 个？
- 是否遵循“问题 -> 机制 -> 截图证明 -> 结论”？

## Visual Consistency

- 是否保持浅色科技风？
- 是否使用统一蓝紫主色？
- AI 是否统一使用橙色？
- 风险是否统一使用红色？
- 通过和完成是否统一使用绿色？
- 背景是否没有影响截图和字幕识别？

## Screenshots

- 截图是否清晰？
- 是否有局部放大？
- 是否圈出了重点？
- 同屏是否最多突出 1 到 2 个重点？
- 是否避免整页截图堆叠？
- 是否避免静态截图停留超过 5 秒？

## Motion

- 动效是否服务理解？
- 是否没有过度旋转、飞入、粒子？
- 是否每 3 到 5 秒有一个明确视觉动作？
- 每个场景是否有入口动画？
- 多场景之间是否有转场？

## HyperFrames

- `npm run lint` 通过。
- `npm run validate` 通过。
- `npm run inspect` 通过，或已记录并解释每个 inspect 警告。
- 没有 `Math.random()`、`Date.now()` 或异步 timeline 构建。
- 没有 `repeat: -1`。
- 视频和音频轨道拆分正确。
